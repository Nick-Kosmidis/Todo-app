# Todo-app

Todo-app is a simple task-management app for keeping everyday to-dos organized. Add tasks, track what is complete, and prioritize work so it's easier to focus on what's next.

## Features

- Add tasks with optional priority and due dates.
- Mark tasks as complete, edit their text or details, and delete them.
- Filter the list to show all, active, or completed tasks.
- Sort tasks by priority or due date, or drag and drop to reorder them.
- Keep your task list in browser local storage.
